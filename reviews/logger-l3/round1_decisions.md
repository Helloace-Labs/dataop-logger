# Round 1 decisions (logger-l3)

Codex round 1: request changes, 4 High, 1 Medium, 0 Low.

1. **High, migration can bypass the review lock check. Changed.** `src/aftershock_logger/review.py`, `transaction`: a review edit now holds the batches lock shared from its lock check to its write, taken before the run's review lock (the same order `set_status` uses), so no batch can be locked, unlocked, moved or migrated in between. `src/aftershock_logger/batches.py`, `_load`: lock-free readers also read the old `batches.json` before listing the per-batch files, and a move writes every file before renaming the old one, so a reader never sees neither. Tests: `test_a_review_edit_waits_for_a_batch_change`, `test_a_reader_racing_the_move_off_the_old_file_still_sees_the_lock`.
2. **High, a read between commit and join can place a new run in a closed batch. Changed.** `batches.py`: the commit choice is now one function, `_choose_for_commit`, used by `join` and by `_place` for any run the logger committed (its manifest has the `batch` key and is not an import). Older and imported runs keep the grouping by identity into a batch for review. Unplaced runs are placed in episode order. Test: `test_a_run_placed_before_its_join_goes_where_join_would_put_it`.
3. **High, import moves leave exports current. Changed.** `batches.py`, `add_runs`: a run an import pulls out of another batch marks that batch's exports stale and is logged there, as `move` does. Test: `test_an_import_that_moves_a_run_marks_the_source_training_sets_out_of_date`.
4. **High, a move does not reach a training set's other datasets. Changed.** `src/aftershock_logger/export.py`: each exported run now records its `batch_id`, and `training_sets` counts `moved_runs`, the runs that are in another batch than the one they were exported from, in any of the set's datasets (older records are matched through their sources). A moved run makes the set out of date. Test: `test_a_move_in_one_dataset_puts_a_combined_training_set_out_of_date_in_the_other`.
5. **Medium, pack records lack kind, station, task and planner. Changed.** `batches.py`, `_set_identity`: each batch file stores `station`, `task`, `planner` and `kind` read from its identity, including batches moved from the old file. `kind` is `teleop` when no policy ran, `model_run` when one did, and `unknown` when the policy was not recorded, so null and unknown stay apart as in L2. The design doc lists the fields. Test: `test_pack_fields_kind_station_task_planner`.

Tests: 227 passed, 1 skipped (the real pre-L3 dataset test, which passes when its path is set).
