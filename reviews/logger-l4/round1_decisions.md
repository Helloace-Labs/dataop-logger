# Round 1 decisions (logger L4)

1. **High, sync ownership race.** Changed. `metadata._write` checks the sync marker again after it takes the dataset lock, so a marker written while a local write waited refuses it. The sync writer writes its marker before it syncs anything (logger L7); `write_synced` itself needs the marker. Test: `test_a_sync_that_begins_while_a_local_write_waits_wins`. File: `src/aftershock_logger/metadata.py`.
2. **High, broken links read as no record.** Changed. A `metadata.json` that is a link, dangling or not, is an error for `load`, `validate`, local writes and export, and is never replaced by a local write; batch following looks for the entry with `lexists`, so a broken entry is skipped there and reported by `validate`. Test: `test_a_link_is_never_read_as_no_record`. Files: `src/aftershock_logger/metadata.py`, `src/aftershock_logger/batches.py`.
3. **High, a proposal without a name on a decided detection.** Rejected. The cloud route for proposals says that when the run already has a detection, whether open, confirmed or removed, a call without a name, or the same name from the same caller, returns the record unchanged, and a call with a name adds a suggestion. The logger follows that route text. A short comment next to the transition table in the cloud model reads differently; that is raised with the lead for the contract, not changed here. Test added for the removed state: `test_a_proposal_without_a_name_on_a_decided_detection_changes_nothing`.
4. **High, writes larger than readers accept.** Changed. Both writers (`_save`, used by local writes and `write_synced`) serialize first and refuse a record larger than `MAX_FILE` before touching the old file, so no write leaves a file nobody can read. The limit stays (64 MiB, room for hundreds of whole steps). Test: `test_a_record_too_large_to_read_is_never_written`. File: `src/aftershock_logger/metadata.py`.
5. **Medium, stored mixed_policy after a sync into a locked batch.** Changed. Every metadata write marks the run's batch for re-derivation in the same batch transaction, so its stored `mixed_policy` follows the effective planner even when membership stays frozen. The locked batch test now reads the saved batch file. Files: `src/aftershock_logger/metadata.py`, `src/aftershock_logger/batches.py`.
6. **Medium, malformed hashes crash validation.** Changed. Uniqueness only looks at string hashes, after the shape checks. Test: `test_a_malformed_hash_is_a_normal_validation_error` (a list, an object and a number; the other run is still checked). File: `src/aftershock_logger/metadata.py`.
