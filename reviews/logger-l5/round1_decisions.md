# Round 1 decisions (logger-l5)

Round 1 was a fallback review (`round1_claude.md`, the reviewer at its usage limit, so a fresh Claude reviewer read commit `6d77bae`): request changes, 2 High, 2 Medium, 5 Low. All are fixed. Because every review so far is a fallback review, this change also gets one Codex confirmation round on the whole change once Codex is available again (timing and file name recorded when it runs).

1. **H1, the tick that first sees a write failure is not recorded. Changed.** `src/aftershock_logger/frame_queue.py`, `FrameQueue.put`: after a write failure, the first `put()` now checks, copies and keeps its frame before it raises, because its action already reached the robot. The queue records when the caller has been told of the stop (`put()`, `check()` or `run.end()`); after that, `put()` keeps nothing more, so memory stays bounded. A frame that fails its checks while a stop is pending still raises the `ControlledStop`. Tests: `test_first_put_after_a_write_failure_keeps_its_frame`, `test_check_counts_as_telling_the_caller`.
2. **H2, frames kept in memory are lost when the stop leaves the RunLogger. Changed.** `frame_queue.py`, `ControlledStop._settle`: the message now says either "N frames quarantined at <path>" or "N frames were NOT written (...)". `src/aftershock_logger/logger.py`, `RunLogger.close`: every stopped run whose frames are only in memory is retried once, then written to `spill_dir` (a new `RunLogger` argument, default `aftershock-logger-spill` in the system temp directory). A `RunError` names where they went, or says they were not written anywhere. README no longer re-raises without a word about the frames: its example prints the stop and points to `run.retry_quarantine()` and the spill folder. Tests: `test_unsaved_frames_are_spilled_when_the_stop_leaves_the_logger`, `test_close_says_when_frames_could_not_be_written_anywhere`, `test_close_retries_the_dataset_quarantine_first`.
3. **M1, fixed 10 s drain and stop timeouts. Changed.** `frame_queue.py`: `drain()` now times out only after `stall_timeout` seconds with no frame finishing, so a slow writer that keeps progressing is never quarantined. `run.queue()` takes `stall_timeout` and `stop_timeout` (10 s defaults, module constants `STALL_TIMEOUT_S` and `STOP_TIMEOUT_S`). After a drain finds the writer hung, the stop does not wait again. Tests: `test_a_slow_but_working_writer_drains_without_a_stop`, `test_end_on_a_hung_writer_stops_without_waiting_twice`.
4. **M2, missing tests. Changed.** `tests/test_frame_queue.py`: tests for H1 and H2 (above), `run.end()` on a hung writer, LeRobot failing after the frame reached its buffer (`test_lerobot_failing_halfway_through_a_frame`, checks the row counts, the buffer reset and that the next run commits), and `put()` returning while the writer is blocked inside `add_frame` with the queue below capacity (`test_put_returns_while_a_write_is_stuck`).
5. **L1, a failed folder sync after the rename makes every retry fail. Changed.** `frame_queue.py`, `write_partial`: the rename is the commit point; a failed sync after it only warns. If the destination already holds this run's record (same `run_id`, length and status), it is returned instead of raising. Test: `test_quarantine_record_survives_a_failed_folder_sync`.
6. **L2, an interrupt during the quarantine write does not block the logger. Changed.** `logger.py`, `Run._quarantine_stopped`: catches `BaseException`, records `quarantine_error`, blocks the logger and registers the run for `close()` the same way, then re-raises an interrupt.
7. **L3, any hidden entry in `quarantine/` fails `validate`. Changed.** `src/aftershock_logger/validate.py`, `quarantine_entries`: only folders named `.<run_id>.*.tmp` (what `write_partial` creates) count as unfinished writes; other hidden files are ignored. Test: `test_hidden_files_in_quarantine_are_not_errors`.
8. **L4, `_copy_frame` copies only arrays and tensors. Changed.** `frame_queue.py`, `_copy_frame`: other mutable values are deep-copied, and tensors are copied to the CPU. Test: `test_copy_frame_copies_mutable_values`.
9. **L5, `close()` can report a timeout for a writer that just finished. Changed.** `frame_queue.py`: the writer clears a `_busy` flag as soon as LeRobot returns, and `close()` reports a timeout only while the writer is still inside LeRobot; otherwise it waits for the append and returns `True`.

SPEC.md and README.md describe the new arguments, the first-put rule, the spill folder and the message.

Tests: `python -m pytest -q`: 258 passed, 1 skipped (246 passed, 1 skipped at round 1; 233 passed, 1 skipped on main).

## Confirmation round (round1_confirm_claude.md)

The fallback confirmation round of `bb917a2` approved the round 1 fixes: 0 High, 0 Medium, 3 Low. All three are fixed.

10. **L6, the default spill folder is temporary and usually on the full disk. Changed.** `src/aftershock_logger/logger.py`, `default_spill_dir`: the default is now a persistent per-user folder, `$XDG_DATA_HOME/aftershock-logger/spill`, else `~/.local/share/aftershock-logger/spill`, never the system temp folder. When the default was used, the close message says it is usually on the same disk as the dataset and recommends setting `spill_dir` to a persistent folder on a different disk. README and SPEC recommend the same for robots. Tests: `test_default_spill_dir_is_per_user_and_persistent`, `test_default_spill_message_recommends_a_different_disk`.
11. **L7, the stop still says "NOT written" after a spill, and the close error replaces the stop. Changed.** `logger.py`, `RunLogger.close`: a spill sets the run's `ControlledStop` `spilled` and `quarantine_path`, and its message says where the frames were spilled. `RunLogger.__exit__`: when an exception is leaving the block, a close error no longer replaces it; a `ControlledStop` gets it as `close_error` and in its message, a warning repeats it, and the original exception keeps propagating. A plain `close()` still raises. Tests: `test_unsaved_frames_are_spilled_when_the_stop_leaves_the_logger`, `test_close_says_when_frames_could_not_be_written_anywhere`, `test_close_error_when_no_stop_is_leaving_the_block`.
12. **L8, test gaps for round 1 L1, L2 and L5. Changed.** `tests/test_frame_queue.py`: `test_write_partial_returns_this_runs_record_and_refuses_another` (the already-present path, matching and mismatched), `test_an_interrupt_during_the_quarantine_write_blocks_the_logger` (logger refused, run registered for `close()`, retry works), `test_close_does_not_misreport_an_idle_writer` (`stop_timeout=0` with an idle writer).

Tests after the confirmation fixes: 264 passed, 1 skipped.
