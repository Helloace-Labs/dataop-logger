# Logger L6, round 1 decisions

| # | Severity | Finding | Decision | Change |
| --- | --- | --- | --- | --- |
| 1 | High | Whole runtime prefixes readable | Changed | `hook_sandbox.py` `_runtime`, `_seatbelt_profile`, `_bwrap_cmd`: the child now reads only the standard library folder (its site-packages hidden), numpy's package folder and bundled libraries, the interpreter binary and its shared library. From those folders only code files (`.py`, `.pyc`, `.so`, `.dylib`) are readable: a seatbelt regex on macOS, each other file hidden behind `/dev/null` on Linux. The probe reads a non-code runtime file; tests read a runtime license file and numpy's `.pyi` and must fail, and a weakened profile is caught. |
| 2 | High | Linux allows fork and aggregate memory | Changed | `seccomp_program` builds a BPF filter passed to bubblewrap with `--seccomp`: fork, vfork, clone, clone3, socket, socketpair and io_uring_setup fail with EPERM, other architectures and the x32 ABI are killed, unknown architectures refuse hooks. One process means RLIMIT_AS bounds all memory. The probe tries fork on both systems. A test interprets the filter for x86_64 and aarch64. |
| 3 | High | Linux output folder unbounded | Changed | The parent precreates the three result files; on Linux the output folder is bound read only and only those files are bound writable, so nothing new can be created and RLIMIT_FSIZE bounds each file. After exit the parent requires the folder to hold exactly those files (both systems). The probe tries to create a new output file. |
| 4 | High | Linux reaches host unix sockets | Changed | The seccomp filter refuses `socket` and `socketpair` (and io_uring). The probe and a test connect to a unix socket listener of the parent; on macOS a weakened profile that allows unix sockets is caught. |
| 5 | High | Forged result metadata can pass | Changed | `_result_meta` checks the full schema in the parent: only `keys` and `reason`, keys unique and from keep, action, reason, reason present exactly when declared and a string, undeclared array files empty, no other files. Tests forge each case from inside the hook. |
| 6 | Medium | Nested JSON crashes the parent | Changed | `RecursionError` is caught and gives `not_run`; tested with a deeply nested result inside the size cap. |
